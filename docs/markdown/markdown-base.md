# Markdown 基础语法

Markdown 是一种轻量级标记语言，用简单符号表示标题、列表、链接、代码等格式，常用于文档、笔记、博客和 README 文件。

## 1. 标题

使用 `#` 表示标题，`#` 数量表示级别，最多通常支持 6 级。`#` 后建议加一个空格。

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 2. 段落与换行

段落之间用空行分隔。

```
这是第一段。

这是第二段。
```

如需在段落内强制换行，可在行尾输入两个空格后换行，或使用 `<br>`。

```markdown
第一行  
第二行
```

## 3. 强调

```
*斜体* 或 _斜体_
**粗体** 或 __粗体__
***粗斜体***
~~删除线~~
```

效果：*斜体*、**粗体**、***粗斜体***、~~删除线~~。

## 4. 列表

### 无序列表

```
- 项目一
- 项目二
  - 子项目
  - 子项目
```

### 有序列表

```
1. 第一步
2. 第二步
3. 第三步
```

### 任务列表

部分平台支持任务列表：

```
- [x] 已完成任务
- [ ] 未完成任务
```

## 5. 链接与图片

### 链接

```
[链接文字](https://example.com)
[带标题的链接](https://example.com "标题")
<https://example.com>
```

效果：[链接文字](https://example.com/)

### 图片

```
![图片说明](https://example.com/image.png)
![图片说明](https://example.com/image.png "图片标题")
```

图片语法与链接类似，前面多一个 `!`。建议填写图片说明，便于无障碍阅读和图片加载失败时显示。

## 6. 引用

使用 `>` 表示引用，可嵌套。

```
> 这是一段引用。
>
> > 这是嵌套引用。
```

效果：

> 这是一段引用。
>
> > 这是嵌套引用。

## 7. 代码

### 行内代码

```
使用 `console.log()` 输出内容。
```

效果：使用 `console.log()` 输出内容。

### 代码块

使用三个反引号包裹代码，并建议标注语言。

````
```javascript
function hello() {
  console.log("Hello, Markdown!");
}
```
````

效果：

```javascript
function hello() {
  console.log("Hello, Markdown!");
}
```

## 9. 表格

```
| 姓名 | 年龄 | 城市 |
| :--- | :---: | ---: |
| 张三 | 20 | 北京 |
| 李四 | 25 | 上海 |
```

效果：

| 姓名 | 年龄 | 城市 |
| :--- | :--- | :--- |
| 张三 | 20   | 北京 |
| 李四 | 25   | 上海 |

对齐方式：

- `:---` 左对齐
- `:---:` 居中对齐
- `---:` 右对齐

## 10. 转义字符

如需显示 Markdown 特殊符号本身，可使用反斜杠 `\` 转义。

markdown

```
\*不是斜体\*
\# 不是标题
\[不是链接\]
```



效果：*不是斜体*、# 不是标题、不是链接不是链接。

## 11. 脚注

部分 Markdown 扩展支持脚注语法：

```md
这是一个脚注示例[^1]。

[^1]: 这里是脚注内容。
```

::: warning 本站不支持脚注
VitePress 默认的解析器没有开启脚注。写了 `[^1]` 不但不会渲染成脚注，还可能被当成链接引用、导致构建报死链。

代替方案：用括号直接注明，或者用 `::: tip` 补充说明。
:::

## 12. 目录

部分平台支持用 `[TOC]` 生成目录。

本站的写法是 `[[toc]]`，放在正文里即可。另外每页右侧的页内目录是自动生成的，不用手写。

```md
[[toc]]
```



是否生效取决于编辑器或平台支持情况。

## 13. HTML 支持

许多 Markdown 编辑器允许嵌入简单 HTML。

```
换行：<br>
按键：<kbd>Ctrl</kbd> + <kbd>C</kbd>
删除线：<del>删除内容</del>
```

效果：按键：<kbd>Ctrl</kbd> + <kbd>C</kbd>

注意：不同平台对 HTML 的支持范围不同。

## 14. 常用规范建议

1. 标题符号 `#` 后加一个空格。
2. 段落之间保留空行，结构更清晰。
3. 代码块尽量标注语言，如 `javascript`、`python`、`bash`。
4. 图片尽量填写 `alt` 说明。
5. 链接文字应描述目标内容，避免只写“点击这里”。
6. 表格内容较多时，保持表头简洁。
7. 不同平台对脚注、任务列表、目录、HTML 的支持可能不同。

## 15. 综合示例

~~~markdown
# 项目说明

这是一个 Markdown 示例文档。

## 功能

- 支持标题
- 支持列表
- 支持代码块

## 示例代码

```python
def hello():
    print("Hello, Markdown!")
```

## 链接

访问 [示例网站](https://example.com)。

> 提示：Markdown 语法简单，但不同平台支持存在差异。
~~~
