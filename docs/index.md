## 这个站点怎么用

按 `Ctrl+K`（macOS 用 `⌘K`）直接搜关键词，比翻目录快。搜索按标题加权，所以尽量输入概念名而不是整句。

左侧目录按「你会怎么找它」组织，不按教程顺序。每个分类的第一页有该分类的完整条目清单。

## 写作约定

新增文章只需要在对应目录建一个 `.md` 文件，侧边栏会自动更新，不用改配置。文件名用数字前缀控制顺序，如 `3.async.md`；显示名取文章的一级标题。

草稿放在 `docs/drafts/`，不参与构建，也搜不到。
