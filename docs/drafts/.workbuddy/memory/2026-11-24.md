## Git 命令速查手册（docs/drafts）

产出 `git-cheatsheet.md` + `assets/git-map.svg|png`、`assets/git-history.svg|png`。

- 结构：30 秒上手 → 心智模型（四区）→ 提交图与指针 → 按场景速查表 → 协作（冲突/merge vs rebase/分支模型）→ 深水区（reflog/reset 急救/rebase 坑/plumbing/配置/大仓库/bisect/踩坑）→ 报错急救表 → 一页纸速记。用 〔浅〕〔深〕〔急救〕 标注难度。
- 图 1：纵向四段管线（工作区→暂存区→本地仓库→远程），左列朝下=记录，右列朝上=撤销/同步。图 2：提交 DAG + 「命令动了谁」矩阵表。
- 关键取舍：**图宽 1080px**。此前做过 1600px 横版，在 1000px 宽的 Markdown 正文里等比缩到 62%，正文被压到 ~7px 不可读。1080 宽内嵌后约 92%，12.5px 字仍清晰。
- 校验方式：`python -m markdown` 渲染 HTML → 无头 Chrome `--screenshot` → PIL 裁剪逐段看。SVG 用 `xml.dom.minidom.parse` 查合法性。
- 坑：XML 注释里不能出现 `--`（如 `<!-- r2 restore --staged -->`），会让整个 SVG 解析失败，Chrome 报 "Unexpected token"。中文 `→` 本身没问题。
- 本机无 cairo（`cairosvg` 装了也报 libcairo-2.dll 缺失），SVG→PNG 走 Chrome headless `--force-device-scale-factor=2`。
